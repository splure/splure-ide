# Icons

Drop Spluride's app icons here with these exact names, and `scripts/prepare.sh` copies them over upstream's:

| File        | Platform | Format                          |
|-------------|----------|---------------------------------|
| `code.png`  | Linux    | 512×512 PNG                     |
| `code.icns` | macOS    | .icns (includes 16–1024 px)     |
| `code.ico`  | Windows  | .ico (includes 16–256 px)       |

Without them, builds use the stock Code - OSS icons.
